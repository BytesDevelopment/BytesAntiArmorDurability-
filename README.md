# BlockArmorDurability  

**BlockArmorDurability** es un plugin para servidores de Minecraft diseñado para bloquear el uso del texture pack llamado **ArmorDurability**. Este texture pack cambia el color de la armadura de los jugadores según su durabilidad, lo que puede afectar la jugabilidad y la equidad en algunos servidores.  

## 🚀 **Características**  
- 🔒 **Bloqueo de ArmorDurability**: Detecta y evita que los jugadores utilicen este texture pack en el servidor.  
- ⚙️ **Fácil configuración**: No se requiere configuración adicional; simplemente instala y funciona.  
- 📜 **Mensajes personalizables**: Notifica a los jugadores cuando intentan usar el texture pack bloqueado.  

## 📥 **Instalación**  

1. Descarga el archivo `.jar` del plugin desde [la sección de releases](#).  
2. Descarga ProtocolLib, mi versión ha sido esta [Descargar](https://ci.dmulloy2.net/job/ProtocolLib/643/)
3. Coloca los plugins en la carpeta `plugins` de tu servidor.  
4. Reinicia el servidor.

## 🔧 **Comandos y Permisos**  
Este plugin no requiere comandos ni permisos adicionales.  

## ❓ **Preguntas Frecuentes**  

### ¿Cómo bloquea este plugin el texture pack?  
El plugin detecta paquetes de texturas específicos que coinciden con el identificador de **ArmorDurability** y rechaza su uso en el servidor.  

### ¿El plugin bloquea otros texture packs?  
No, este plugin está diseñado exclusivamente para bloquear **ArmorDurability**.  

### ¿Es compatible con todas las versiones de Minecraft?  
El plugin es compatible con versiones desde **1.8**, desconozco si es compatible con el resto.
